# v2.1.0 综合优化 PR 最终整合说明

来源：`suining-v2.1.0-comprehensive-optimization.zip`；原 PR #206。
在 #197、#199、#201、#203、#204 合并后，重新以最新 `preview` 构造整合树。

## 实际采纳
- MySQL 业务连接池与独立探针池设置两分钟最大空闲时间。
- `/auth/session` 初始化账号检测使用 `EXISTS` 替代全表 COUNT。
- 设备防重放 nonce 每批最多 5000 行、每次最多 4 批限量删除。
- 照护网关显式要求 TLS 1.2+，限制连接、握手和响应头时间。
- 小型通知网关响应限量排空；腾讯短信仅接受合法且明确的 `{"result":0}`。
- 保留 #201 已修复的文件凭据读取和配置快照；增加密钥文件、
  缺文件、TLS、短信模糊应答和 nonce 批次/错误的回归测试。

## 不重复合并
- #201 已完善的 `config.Secret`、运行时配置快照、通知环境读取和服务端启动逻辑。
- 没有一致基准的 JSON 缓冲池，以及可能更改授权时序的缓存 Singleflight。
- 不可正确处理部分写出 HTTP 响应的泛用 panic Recover。

## 合并和正式发布要求
两项必需检查 `Core CI / required` 与 `Security gate / required`
均应通过；不改数据库 Schema、对外 API 路由或新增依赖。
公网通知网关真实连通、生产型数据恢复和硬件验收仍另行完成。
