# 岁宁 2.1.0 正式版 · MySQL 单库 / Windows 桌面交付

这是稳定渠道发布。Setup、Portable、Source 和可选独立原生服务端来自同一源码 SHA；确切来源及校验值见 `release-manifest.json` 和 `SHA256SUMS.txt`。

## 本版更新

- 架构：Tauri 2 / Rust、Vue 3 + TypeScript、Go 原生服务、MySQL 8.4 单库。会话、健康采样、审计、照护任务和图片 BLOB 使用 MySQL；不再运行 PostgreSQL 分析或 S3 业务存储。
- 健康隐私：健康采样、快照、统计及告警证据的加密保护与读取一致性（#176），密钥轮换和迁移边界明确；不降低服务端授权。
- 性能与交互：静态资源 gzip 和缓存（#178）、设置与登录体验修复（#179）、路由代码块预加载（#180）。
- 社区：增加 Issue 表单、无障碍反馈、行为准则，完善架构文档与真实项目状态徽章（#181、#182、#184）。
- 打包：修复旧路径造成的源码归档失败（#185 的修正已纳入本次正式源码）。一套 Windows 安装、便携和源码 ZIP 与可选无字体原生服务端。

## 安装、升级和限制

安装包不包含数据库。需独立部署 MySQL 8.4，配置 `SUINING_MYSQL_DSN` 与随机 32 字节 Base64 数据加密密钥，并保管恢复用密钥。升级旧 PostgreSQL/S3 版必须先停写、备份，再按 [MySQL 单库迁移手册](../MYSQL_ONLY_MIGRATION.md) 执行离线迁移；安装不会自动转换数据库和图片。

本次维护者明确要求**不重新运行完整远端 CI**。新 SHA 的本机实际编译、版本核对、安装和卸载验收以发行清单及日志为准；不得借用其他提交的 CI 成绩。HarmonyOS 真机、真实短信网关、生产数据迁移及持续负载均非本轮验证范围。桌面绑定回环地址，外部手表 SOS 需独立常驻服务和人工值守。Windows 二进制默认不签名，请从官方 Release 下载并核对 SHA-256。

2026-10-22 的旧预览 Release 已按维护者要求归档为 [`v2.0.7`](https://github.com/WatchTestCs/smart-elderly-watch-management/releases/tag/v2.0.7)，但旧附件**未重新编译**，程序内部版本仍显示 2.1.0，源码仍为 `e3cf064`；原 `v2.1.0` Git 标签也保留。2026-11-22 的正式版使用独立标签 `v2.1.0+20261122`，两者不可混用。
