# 岁宁 2.1.0 · 双库桌面完整交付

本版基于 `preview`，统一 Windows 安装程序、免安装版和完整源码的产品版本为 **2.1.0**。附件的精确源码提交、构建运行及实际打包检查见 `release-manifest.json`；下载完整性见 `SHA256SUMS.txt`。这是预览渠道发布。

## 下载与使用

- `Suining-Setup-2.1.0-win-x64.exe`：Windows x64 安装程序。复用系统 WebView2，仅缺失时联网静默补装。
- `Suining-Portable-2.1.0-win-x64.zip`：完整解压后运行 `suining.exe`，保留同目录 `suining-server.exe` 和使用说明；需要系统已有 WebView2。
- `Suining-Source-2.1.0.zip`：同一发布提交的完整 Git 源码，包含字体、许可证、构建脚本和数据库迁移；不含依赖缓存、用户数据或私钥。
- `release-manifest.json`、`SHA256SUMS.txt`、`Release-Notes-zh-CN.md`：来源、检查范围、校验值和离线说明。

默认数据目录为 `%APPDATA%\岁宁`；数据库独立部署，安装包不包含 MySQL 或 PostgreSQL。没有默认管理员或通用密码。安装版和免安装版均**未签名**，可能出现未知发布者提示。

## 本版整合

- 继承 2.0.6 的 MySQL 业务主库、PostgreSQL 异步分析、照护闭环、档案与设备修复及健康采样整合。
- 整合后续 Go 1.23 适配、后端修复和已提交的性能改进；不把历史本地压测视为本版完整验收。
- PR #24：Outbox 连续满批时短暂让出 10ms 后继续；队列总数改为每 30 秒采样，失败不阻断分析投影；仅将尚未失效的日缓存标为 dirty。保留事务和 PG 成功后确认 Outbox 的顺序。
- PR #25：主 MySQL 池默认空闲连接上限从 5 改为 20，最大连接数仍为 20，另保留 1 个健康探测连接。`MYSQL_MAX_IDLE_CONNS` 允许 0–20；设为 5 并重启可恢复原空闲池行为。多实例部署应核对数据库连接与内存预算。
- 独立 MySQL 突发查询微基准的 p99 约降低 52%；该数字不代表完整 HTTP 写入、SOS 送达或生产吞吐收益。`InterpolateParams` 和普通 INSERT 替换 UPSERT 的实验方案均未启用。

- 同时收录 `HEALTH_LATE_DEVICE_LOCK=1` 可选实验：默认不启用，原设备锁顺序保持默认；启用时提交前重新核对设备密钥、状态、归属和绑定版本，变化则回滚。切换前必须停止并排空全部旧写入者，禁止不同锁顺序实例混跑；普通部署不要设置该变量。详见后端 README。
- OpenAPI 版本从后端 `VERSION` 生成并参与统一版本校验，避免文档停留在旧产品版本。

## 升级

1. 备份数据库和 `%APPDATA%\岁宁` 中的图片等资料，关闭旧应用后安装或解压新版本。
2. 当前桌面配置为 `SUINING_MYSQL_DSN` 和 `SUINING_PG_ANALYTICS_URL`。MySQL 使用原生 DSN，PG 使用 URL；不要把旧 PG 地址作为 MySQL 配置。
3. 旧 PG 业务库需要显式离线迁移：停止写入，先对空 MySQL 目标执行 `backend/cmd/transfer-postgres` 预检查，再决定 `--apply`；图片另行复制。安装不会自动迁移数据库。2.0.0 Java/H2 不在该导入工具的承诺内。
4. 长期机构值守应使用独立常驻后台与人工应急流程，不能依赖桌面窗口保持打开。

## 检查与限制

发布前要求同一源码提交的双 Go 版本 CI、真实临时 MySQL/PG 集成和 race、前端构建、静态检查及 Windows 打包成功。打包脚本核对产品版本和 sidecar 哈希，检查解压后的免安装版及静默安装后的真实程序能启动并提供内嵌界面，检查父进程终止后的服务清理，以及卸载保留测试用户资料。实际结果以随包清单和对应 Actions 日志为准。

无界面启动检查不等于可视窗口和完整交互验收；未验证 Windows 10 实机、缺失 WebView2 时的真实补装、真实手表、短信网关、生产数据迁移或本版 20 分钟 HTTP 耐久测试。历史 Java/Kotlin CodeQL 配置缺失警告不等于 Go/JS 扫描失败，也不能称所有历史扫描配置均通过。

历史 2.0.0 及重要功能版本保留；小型源码维护版可整理其 Release 页面，原 Git 标签和提交不移动。
