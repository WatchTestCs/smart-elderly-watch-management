# 岁宁 2.0.1 Preview

本版本基于 `preview`，是 2.0.0 Preview 之后的补丁发布。

## 重点变化
- 设备密钥改为不可逆摘要存储，并加入 V3 迁移与回归测试。
- 新增 V4 设备—老人关系约束；删除老人时对仍绑定设备给出明确冲突反馈。
- 补强删除流程、浏览器回归、数据库事务与迁移测试。
- 完善 CI、UI Quality、CodeQL 与 Windows 发布证据链。

## Windows 资产
- `Suining-Setup-2.0.1-win-x64-unsigned.exe`
- `Suining-Portable-2.0.1-win-x64-unsigned.zip`
- `SHA256SUMS.txt`
- `release-manifest.json`
- `sbom.spdx.json`

## 发布验收
Release 仅在同一 GitHub Actions 运行完成构建、Setup 静默安装、启动安装后的真实 `Suining.exe`、确认内置 Java 服务就绪、卸载、摘要/SBOM/attestation 后创建。`v2.0.1-preview.1` tag 最后创建并指向该已验收 commit。

## 签名状态
**本次远程发布资产未使用公开受信任的 Windows 代码签名证书，文件名明确标注 `unsigned`。** 本地自签名不代表 Windows 公开信任或 SmartScreen 信誉。

## 已知边界
Windows 10 尚未独立实机验收；真实手表端到端联调、真实短信发送、完整第三方渗透测试与正式性能基准仍未完成。
