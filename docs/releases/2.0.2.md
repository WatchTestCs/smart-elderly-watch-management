# 岁宁 2.0.2 · 更新安装包与 Linux 附件

按用户明确要求替换现有 `v2.0.2-preview.1`，保留软件版本 2.0.2，不新建版本。发布只对应 `preview`；既有 2.0.2 用户需要重新下载安装包，本轮不提供自动更新。

## 下载文件

- `Suining-Setup-2.0.2-win-x64.exe`：约 28.8 MiB，Tauri / Go Windows x64 安装包。不附带 WebView2，检测系统已有组件，仅缺失时联网下载微软引导程序并静默补装为 Windows 共享组件。
- `Suining-Linux-amd64.tar.gz`：用户提供的 Linux x86-64 Go 服务与浏览器启动包，保持原始内容，不是当前 Windows 源码的 Linux 重编译。
- `suining-db-manager_1.0.0_amd64.deb`：Linux PostgreSQL 管理工具，组件版本 1.0.0，不包含数据库服务。修复了原包非法的中文 Package 字段，程序负载未变。
- `SHA256SUMS.txt`、`release-manifest.json`：文件校验与来源说明。
- `verification.json`：Windows 前序验收及本轮 Linux 基础检查的证据边界。
- `sbom.spdx.json`、`THIRD-PARTY-NOTICES.txt`：Windows 源码锁文件清单及依赖许可，不覆盖用户提供的 Linux 二进制依赖。

## 数据库与离线行为

PostgreSQL 独立部署。软件没有数据库也能打开正常界面，只有依赖数据库的操作就地提醒；已登录后断线保留页面和输入，退出登录仍可用。后台自动重试已配置的数据库地址，网络恢复后继续连接；失败写入不自动重放。必须预先配置连接地址与凭据，软件不能自行推断数据库。

没有默认管理员手机号或密码，数据库准备好后首次创建管理员。旧 H2 数据不会自动转换，升级前备份；Linux 附件与当前 Windows 后端的迁移版本不能假定完全一致。

## 检查与限制

Windows 沿用前一轮 13 项真实 Tauri / PostgreSQL 验收、1232 项浏览器检查，以及最终轻量 Setup 的实际安装、启动和卸载结果。本轮仅进行文件、元数据和上传校验，不重复完整测试。

Linux 仅检查压缩包结构、服务器 ELF x86-64 架构及 DEB 元数据，未执行程序、安装或连接生产库。详细步骤与限制见仓库 `docs/LINUX.md`。

Windows 使用本机自签名，不是公开受信任 CA，可能出现未知发布者提示。本机已有 WebView2，未验证干净系统缺失组件时的真实补装。未测量性能，也未手动触发或查询 GitHub Actions。
