# 岁宁 2.0.2 · Tauri Windows 预览版

发布分支仅为 `preview`，标签为 `v2.0.2-preview.1`。本版替换桌面和服务架构，保留既有 UI、山水标志与字体。

## 安装包与要求

下载 `Suining-Setup-2.0.2-win-x64.exe`，Windows 10/11 x64。NSIS 安装包内含 Microsoft WebView2 离线安装器，不要求另装 Java、Node.js、Go 或 Rust。数据库独立部署为 PostgreSQL；没有数据库也能打开软件并查看连接状态，业务操作仍需数据库。

没有默认手机号或密码，空库首次启动由使用者创建管理员。连接串通过 `SUINING_DATABASE_URL` 配置，不要把生产口令提交到仓库。

## 本版变化

- Tauri 2 / Rust 桌面壳管理 Go 子进程，移除 Electron 和随包 Java。
- 真实 Vue 页面与 SQL 迁移编入 Go 程序，支持从任意工作目录启动。
- 数据库连接在后台重试；断线时明确返回 503，连接恢复后重新检查会话，不自动重放失败写入。
- 受限原生初始化命令不向页面暴露桌面令牌；页面来源、导航与 Tauri 权限受限。
- 保留 Go 审查修复：图片预解码限制、家属绑定竞争、设备与长者关系、坐标/SOS、退出权限及列表和编辑契约。
- 桌面默认最大化，F11/Escape 切换与退出全屏，正常关闭结束 Go 服务。

## 升级前必读

2.0.1 的 H2 文件不会自动转换成 PostgreSQL。升级前保留旧安装包、完整用户目录与数据备份；已有业务数据需单独导出、映射和导入。卸载保留用户资料不代表旧数据已经迁移。先在测试环境核对记录再用于实际照护。

## 签名与验证边界

Setup、桌面主程序与 Go 服务采用本机自签名 Authenticode；证书不是公开受信任 CA，没有安装根证书，且没有时间戳。Windows/SmartScreen 仍可能提示未知发布者。不能把本版描述为公开受信任签名发行。

本机已有 WebView2，因此未验证全新 Windows 上无运行时的离线安装；未进行所有 Windows 版本、真实手表、短信、生产数据迁移或性能测量。依赖清单为锁文件生成的 SBOM，不是零漏洞保证。未手动运行或查询 GitHub Actions。
