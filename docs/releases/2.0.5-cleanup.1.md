# 岁宁 2.0.5 · 已验证死代码清理修订

这是基于原 `v2.0.5` 的**源码维护修订**，采用独立标签 `v2.0.5-cleanup.1`。原 `v2.0.5` 标签、Release 和下载文件保持不变，避免同名源码 ZIP 被静默替换。

## 证据与删除范围

在 `preview` 的 Go 后端运行 `golang.org/x/tools/cmd/deadcode@v0.36.0 -test ./...`，扫描**包含测试入口**的函数可达性，报告以下 4 个不可达函数，已按函数边界删除：

1. `internal/auth/password.go` — `IsNumeric`
2. `internal/handlers/util.go` — `page`（同步删除其不再使用的 `strconv` 导入）
3. `internal/response/response.go` — `FailWith`
4. `internal/session/session.go` — `Store.Rotate`

以上删除**不改变既有 HTTP 路由、数据库迁移、SOS 通知状态机、家属端和桌面启动逻辑**。静态可达性不等于对所有未来动态调用与第三方源代码复用作出承诺；因此仅移除具有静态证据且未作为实际外部协议入口的辅助函数。

## 关于死文件

没有可靠证据证明需要额外删除完整的源码或运行文件。尤其 `backend/internal/handlers/web/.gitkeep` 必须保留供 `//go:embed all:web` 在纯 API 构建场景正常工作；`handler_old.go` 仍注册真实设备/老人路由；`oldIot/src/assets/css/index.css` 仍由 `main.js` 导入。数据库历史迁移、构建/发布工作流、字体许可和静态资源未被误删。

## 验证与发布

该修订需通过 Go race/build/vet/gofmt、前端生产构建、UI Quality、Security 才能合并。源码 ZIP 由 GitHub `git archive` 产生，附 `SHA256SUMS.txt`。**不包含预编译 Windows/Linux 程序或真实设备与网关验收**。
