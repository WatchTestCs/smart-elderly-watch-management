# 岁宁 2.0.3 · 源码维护版本

本次为 **2.0.3 源码发布**，基于 `preview` 分支的已合并重构。**不包含 Windows 安装器、Linux 可执行文件或数据库服务**。

## 主要变化：拆分过长源文件

- **Go 后端**：将原约 2,905 行的 `handler_old.go` 按老人档案、设备路由与协议、数据解析与访问、遥测、设备管理、告警与处置、手表信息和位置等职责拆分。另将社交/公告/图片/SMS、健康指标/步数、家属/邀请码分别拆分成相对独立的模块。
- **Vue 前端**：从大型页面抽离 Options API 脚本；将设备页面的列表、告警、自动刷新及设备管理方法拆分为独立文件，以便维护。
- **全局样式**：将 `App.vue` 的大段 CSS 拆为基础样式、组件样式与家属/响应式样式，并保持加载顺序。
- **文档和清理**：添加 `docs/REFACTOR_2.0.2.md` 解释模块边界；清理已确认冗余的静态目录占位文件并更新文件索引。

上述调整以**保持原有业务接口、路由和数据库语义不变**为目标，不应描述为新增业务功能。保留历史迁移、必要运行资源和许可证。

## 检查与发布范围

合并重构后的 `preview` 分支已通过 GitHub Preview CI（Go 测试/race/build/vet、前端构建）、UI Quality 和 Security 工作流。本源码版本使用 GitHub 归档，不代表重新进行了真实手表、短信服务、Windows 安装或 Linux 部署测试。

源码 ZIP 不包括 Git 历史，也不包括未提交的本地文件、用户数据库、凭据或安装包。可通过 `SHA256SUMS.txt` 验证下载完整性。

**源码不是现成安装包。** 构建和部署请查阅 `docs/BUILD.md`、`docs/LINUX.md`、`docs/REFACTOR_2.0.2.md`。
