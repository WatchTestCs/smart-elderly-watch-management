# GA Readiness 补丁复审与最终整合

来源：上传补丁 `suining-v2.1.0-ga-readiness-patch.zip`，原 PR #205。
本次在已合并 PR #201、#203、#204 等改动后做重新整合，**只保留独立增量**。

## 实际保留
- CSRF 403 使用现有 `response.Error` typed DTO，字段、状态不变。
- CSRF 放行、拦截的单元回归测试。
- Rust 手表模拟器 HMAC 签名与 nonce 的确定性、范围/长度测试。
- 设备页面从隐藏状态首次恢复可见时立即刷新采样的回归测试。

## 删除的重叠或不适配内容
- 六个独立数据回填命令、统一运维 CLI、`protect-notes` 改写：
  PR #201 已合并，且其批次事务和候选预算比原 PR #205 更适合运维环境。
- `config`、风险管理器、响应日志、设备轮询实现：
  PR #201 已提供并通过两项必需门禁。保留当前版本避免退化或重复。
- 原补丁的旧时间配置和关于 GA 就绪/100% 兼容的声明：
  没有真机、数据恢复、生产形态负载和打包验收证据，不能认定。

## 检查与发布边界
必须通过 `Core CI / required` 和 `Security gate / required`，再合并。
此整合不更改数据库迁移、公共 API 路径、部署配置或依赖版本。
正式 GA 发布仍须真实硬件与生产形态数据迁移/回滚等验收。
