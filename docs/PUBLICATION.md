# preview 分支发布约定

本仓库只操作并提交 preview 分支。保留 main 与其他分支，不强推，不改写既有历史，也不自动创建合并请求或合并。

本轮追加当前桌面版源码，为文件分别编写提交说明，并发布 v2.0.0-preview.1 预发布标签。标签指向 preview 最终提交，安装包通过 GitHub Releases 分发。原 archive-2026-10-13 RAR 发布保持不变。

每个文件的职责见 FILES.md 和 file-descriptions.json。GitHub 文件列表的说明来自最近提交消息，不是文件自身描述字段；因此本轮在本地生成逐文件提交，再一次性推送完整分支。

运行包包含自带运行环境与开源许可；SHA256SUMS.txt 覆盖下载资产。公开证书不含私钥，不将自签证书自动加入根信任。
