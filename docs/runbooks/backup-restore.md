# Runbook: Backup and Restore

## Backup

1. 完全退出岁宁。
2. 确认 Java 后端进程已经退出。
3. 复制整个 `%APPDATA%\岁宁` 到新的备份目录。
4. 对备份生成 hash 或压缩包校验。
5. 不只复制 H2 单个文件；图片和其他用户数据也属于备份。

## Restore

1. 先保留当前数据目录副本。
2. 保证岁宁完全退出。
3. 将目标备份恢复为完整数据目录。
4. 首次启动后检查登录、老人档案、图片和最近记录。
5. 若应用/数据库版本跨越了 schema migration，按该版本专用迁移说明执行。

不要使用测试/验收数据库覆盖真实用户目录。
