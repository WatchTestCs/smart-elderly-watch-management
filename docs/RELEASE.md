# 2.0.2 发布流程

仅操作 `preview`；`desktop/version.json` 是产品版本入口，validate-version.ps1 核对 Rust、Tauri、前端及 Go 版本。下次实际发布从 2.0.2 递增至 2.0.3，不把本地重编译当作新版本发布。

1. 从干净 preview 源码完成本地测试与 Windows Tauri 构建。
2. 验证 Setup、数据库离线启动、恢复、原生初始化与退出，记录限制。
3. 更新 README、发布说明、文件索引、校验和、依赖清单和签名状态。
4. 提交并推送 preview，发布 `v2.0.2-preview.1` 指向该提交；EXE 放 Release，不提交源码树。

本轮发布由用户明确授权。后续发布或远程验证需有对应请求，不能沿用本轮权限。自动 Release 工作流仅允许手动触发，避免推送版本文件就重复发布。不得把自签名标注为受信任签名，也不得自动安装根证书。
