# v2.1.0 前端补丁复审与最终整合

来源：用户上传 `suining-frontend-v2.1.0-ultimate.zip`，原 PR #207。
以已合并 #197、#199、#201、#203、#204 的 `preview` 为基线进行增量适配。

## 保留
- 高对比度 CSS 变量和大字偏好持久化，以及其他浏览器标签的状态同步。
- 离线提示独立呈现，不用网络事件遮挡或覆盖数据库错误与原有业务页面。
- 健康采样简报的时间来源检验、非诊断性状态说明及手动语音播报；
  无时区/无效/超前时间戳不能错误宣称“刚刚同步”或正常健康。
- 图表尊重减少动画、大字和高对比度偏好，**保留完整数据点与异常峰值**。
- 新增用户偏好、网络状态、时间边界和图表完整性回归测试。
- 与 #199 的显示器原生 Hz 与 WebView 帧调度诊断并存，不覆盖其组件与测试。

## 去除及原因
- 360 点等距抽样：可能丢失短暂心率/血压异常峰值。
- 设备模型手写部分字段对比：可能漏掉后来新增或嵌套的状态字段。
- 手工 vendor 分包：缺少首屏大小、缓存命中与真实设备基准证据。
- 登录 MFA/注册/初始化/运营概览的大量无关格式与结构改写。
- 已由 #201 合并的 `visiblePolling` 首次唤醒行为，不再重复修改。
- 未经过真实平台验证的桌面 F11/Esc 快捷键说明。

## 验收与限制
前端 TypeScript、ESLint、Vitest、生产构建和 UI 检查必须通过，继续执行
两项必需门禁 `Core CI / required`、`Security gate / required`。
真实桌面环境的中文语音包/Web Speech API 可用性与交互体验需人工确认。
摘要仅反映可核对的采样时间，不等同于健康诊断、设备在线或最近同步证明。
