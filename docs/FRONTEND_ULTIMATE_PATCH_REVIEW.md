# v2.1.0 前端优化包：审查、采纳与适配

来源：用户上传的 `suining-frontend-v2.1.0-ultimate.zip`（说明文件和 19 个源码/测试文件）。
适配基线：`preview` @ `4aefaa46508afe70f1f8b1864f7cd23afa229b76`。
本 PR 采用独立增量提交，不直接解压覆盖，也不包含未合并 PR #205 的重复改动。

## 采纳（并纠正）

- 新增高对比度 CSS 令牌和设置项，保留原有大字模式；同源其他标签的 `storage` 事件同步偏好，并处理 `localStorage.clear()`。
- 浏览器离线状态提示使用 `navigator.onLine` + 事件，但**只视作网络提示，不作为服务端可用性判断**；即使离线也不遮挡既有页面内容或覆盖数据库真实错误。
- 健康采样摘要和**用户主动点击才播报**的系统语音；不添加第三方语音服务。对 `legacy-unzoned`、无时区、无效及明显未来时间，不伪造“刚刚同步”或“已超过 6 小时”；仅称“采样时间”，不等同于设备在线、数据上传成功或健康正常。
- 健康展示数据使用 `shallowRef`；时间文案每分钟刷新，播报在新请求/卸载时停止。
- 图表适配大字模式、减少动画，**保留全部采样点**，不实施会跳过异常尖峰的等距抽样。
- 为偏好同步、在线状态、健康摘要时间边界和图表极值保留添加回归测试。

## 不采纳

- `useDevices.ts` 的手工字段比较：仅比较已列出的字段，未来设备新增字段时容易漏刷新；保留原有深比较以维护完整数据语义，后续优化须有业务字段覆盖测试和基准。
- `recordChartOptions.ts` 简单等距压缩到 360 点：会遗漏心率、血压或睡眠异常极值，属于不可接受的数据表现偏差。
- `vite.config.ts` 的手工 vendor 拆包：无构建体积/加载耗时基准，且依赖间可能产生共享 chunk 耦合；保留当前构建配置。
- `Login.vue` 将 MFA 两个输入压缩进一个 FormItem：可能破坏表单间距与错误关联；保留现有形式。
- `Register.vue`、`Setup.vue` 的格式改动及 `OperationsOverview.vue` 的整文件换行符变更：无实质增益，不制造无谓 diff。
- 桌面端 F11/Esc 帮助文字：未通过 Tauri 全平台快捷键行为核实，不声称已有实现。
- `visiblePolling.ts` 与相应测试：已经由未合并的 PR #205 涉及；为避免重叠，保留现有 `preview`，不复制。

## 合并与验收

本 PR 不新增依赖、不修改数据库/API 契约。应以 GitHub CI 的前端 `lint`、`typecheck`、Vitest、构建及 UI 质量检查为准。手动验证高对比度（包含弹窗）、多标签同步、离线场景、摘要定时变化，以及桌面端实际语音支持情况。浏览器语音引擎可用性和语言包依赖用户设备。

**采样摘要仅用于展示已上报记录，不提供医疗诊断、告警处置或生命安全承诺。**
