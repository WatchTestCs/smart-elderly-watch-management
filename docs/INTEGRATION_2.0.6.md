# 2.0.6 preview 源码整合记录

日期：2026-10-19。远程基线为 `447ca70a2e5d2fba2dd82ad1e3d949031c0b3820`。在该提交上整合本地 2.0.6 的 UI、照护与数据闭环、MySQL 主库＋PG 分析、版本和构建修复，保留远程健康采样实现及历史文件。仅更新 `preview`，不修改 `main`、标签或 Release。

## 整合内容

- 保留远程健康采样标准化、批量写入、同版本去重与冲突、增量游标、家属隔离、绑定版本及单来源统计。原有 Apple 导入和 alertEvents 暂缓范围保持不变。
- 健康存储改用当前数据库事务接口；在持有全局修订时钟锁的事务中递增修订，保持提交顺序游标，不使用 MySQL 不支持的 `UPDATE … RETURNING`。
- 新增 MySQL `0003_health_samples.sql`，保存采样、修订记录与时钟；绑定变更触发器覆盖绑定和解绑，普通设备编辑不递增版本。
- 远程 PG `0007_health_samples.sql` 保持原样。新增 PG `0008_health_query_columns.sql`，为兼容测试和旧库维护补齐查询字段；统计统一使用来源、语义、删除标记和 UTC 微秒时间字段，避免 PG JSON 时间表达式进入 MySQL。
- 离线导入识别 PG 0006、0007、0008 结构；兼容 0007 仅有 JSON 的采样表，保留采样、变更记录、修订时钟和设备绑定版本。源库只读、目标非空拒绝导入，失败时目标事务回滚，图片仍需单独复制。
- MySQL 为全部业务 API 的唯一主库。当前 PG 投影仍覆盖旧健康/日常记录、轨迹和照护，不自动复制新采样表；新采样接口没有替换旧图表、日报或告警入口。
- 同步中英文产品介绍、工程及前后端 README、双库配置、构建、测试和版本说明。保留其他后台权限范围，不扩大护理员／审计员岗位限制。

## 二进制与验收边界

此前本地 2.0.6 安装版、免安装版及旧源码 ZIP 为整合前产物，未包含这次远程健康采样适配。本次提交的是整合源码、文档、配置及验证摘要；不将安装器、数据库、运行凭据、缓存或 node_modules 提交到 Git，不上传或替换 Release。需要对应二进制时，从当前源码执行 `desktop/build.ps1` 重新构建，安装器默认未签名。

本轮未重新构建原生 Tauri 安装包、运行安装程序、验收原生窗口、接入真实手表／短信网关、迁移生产数据或验证长期负载。MySQL 8.4 Compose 模板仅静态检查，真实双库测试使用上述版本。此前 PG 停机业务流程和恢复分析验证记录仍见 [双库指南](DUAL_DATABASES.md)，不能声称此次重新执行了那套停机浏览器流程。
