# 架构、数据流与优化

## 启动与请求

Electron 主进程校验随包组件摘要，启动随包 Java 服务。服务完成数据库初始化后通过本机就绪文件返回动态端口；桌面窗口只加载该地址。渲染页面不获得 Node.js 访问权限。

Vue 3 页面通过同源接口访问 Spring 服务。登录建立服务端会话，写操作校验 CSRF，家属访问校验老人关联关系。首次管理员设置额外要求仅保存在桌面进程中的随机令牌，并用数据库行锁阻止重复创建。

H2 文件、上传图片与日志位于用户数据目录，不放在安装文件夹。退出桌面时请求服务正常关闭，并确认 Java 进程退出；桌面父进程异常消失时后端监测并关闭。

## 当前构建边界

oldIot 使用 Vue 3 / Element Plus / Vite 8；careold 使用 Spring Boot 3.5 / Spring Security / JDBC / H2；desktop 使用 Electron 44、Temurin Java 21 和 NSIS 3.12。Java 服务由当前 Maven 3.9 构建，旧 Maven 包装脚本已移出。

页面、图表按需加载，关闭图表释放资源。通过窗口排序一次取得最新记录，索引覆盖关联和时间条件。每日记录按唯一键原子更新，取消每次上报前的历史去重扫描；公告图片组使用序列，监护人主键使用自增。连接池限制为 1–4 个连接。

家属的单人健康、活动和位置查询在限定长者或设备后取最新一行，使用现有复合索引，避免对其他人的历史数据做窗口排序。设备心跳在一次更新内维护上报与在线标记；设备上报、SOS、告警处置和邀请码批量生成具有事务边界。日数据区分缺省与零值，缺省项保留原值。上报判定使用设备档案阈值，新增或编辑阈值先校验高低值与范围。细节及本地验收见 [本轮优化记录](BACKEND_SCREEN_REFINEMENT.md)。

短信通过标准 HTTP 客户端与既有 JSON 组件实现，在事务提交后进入有界队列，避免数据库锁等待网络。未配置凭据时不发送。

设备接口按 HTTP DTO/校验 → DeviceService 业务与事务 → JDBC DAO 分层，控制器不再直接写 SQL。业务表格按页读取数据库，返回总数，前端不再依赖先取全量再切片。离线检测由独立定时任务维护，读列表无副作用。

数据库使用 Flyway 版本迁移；已有文件升级前先生成可恢复备份，重复日记录旧行归档后再建立唯一索引。启动读取版本，拒绝软件降级打开未来数据库。H2 为明确选型，MySQL 模式不代表完整跨数据库兼容。详见 [本轮核验记录](PREVIEW_ISSUE_REMEDIATION.md)。

Leaflet 随页面分块本地加载。在线地图只在用户操作后请求明确的 OSM 图片域；组件卸载时移除地图与尺寸监听。接口仍保持同源，桌面私有令牌只注入本机服务请求，不发给地图提供方。

## 隔离与发布

Electron 启用 sandbox、contextIsolation 和 ASAR 完整性验证；关闭 RunAsNode、Node 环境参数、Node 调试参数与 file 额外权限。拒绝远程导航、新窗口、WebView 与权限申请。后端和主要运行文件摘要保存在受校验 ASAR 中。

运行环境固定版本及摘要保存在 desktop/runtime-lock.json。安装器每用户安装，卸载只删除安装器记录的文件，保留数据及未随包提供的文件。

没有运行性能基准；上述为已实施的工作消除和依赖减少，不是加速倍数承诺。首次结构初始化与当前版本覆盖安装已经测试，未来破坏性数据库变更需独立迁移设计。
