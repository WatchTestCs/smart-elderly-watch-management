# ADR-0004：面向老年照护场景的 UI 设计契约

- Status: Accepted
- Date: 2026-10-16

## Context

系统用于老人、家属和管理人员的照护任务。单纯遵循通用组件库默认值不足以保证可读性、可点击性、错误恢复和大字模式下的任务完成能力。

## Decision

UI 优化以“任务可完成性优先于装饰”为原则，并采用仓库级设计契约：

- 主要交互目标不小于 48px；辅助交互目标不小于 44px；
- 正文默认不低于现有 16px 基线；
- 大字模式必须保留完整任务能力，不能通过隐藏关键操作换取布局稳定；
- 状态不得只依赖红/绿色；
- 键盘焦点必须可见；
- 对话框负责正确进入焦点并在关闭后恢复焦点；
- 空状态、加载状态、错误状态必须给用户下一步；
- 破坏性操作明确对象与后果；
- 窄屏优先重排为卡片/纵向任务流，而不是仅压缩桌面表格；
- 健康数据文案描述事实和数据新鲜度，不做未经依据的诊断结论。

UI 改动必须接受浏览器级 a11y、触控目标和视觉回归检查。详细规则见 `docs/UI_UX.md`。

## Consequences

Element Plus 只是实现工具，不是最终设计标准。后续 CSS 与组件拆分必须围绕统一 token 和交互契约，而不是按页面继续累积例外。
