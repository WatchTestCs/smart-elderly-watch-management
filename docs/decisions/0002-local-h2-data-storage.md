# ADR-0002：H2 文件数据库与用户数据目录

- Status: Superseded by [ADR-0006](0006-tauri-go-postgres.md)
- Date: 2026-10-16

## Context

项目定位为可离线运行的本机照护管理桌面应用。安装目录会被升级和卸载操作管理，不适合作为用户记录的持久化位置。

## Decision

业务数据库使用 H2 file mode。数据库、上传图片与日志统一放在 Electron `userData` 目录；Windows 默认落在用户配置目录下的“岁宁”数据区域，而不是程序安装目录。

安装、覆盖升级和卸载不得默认删除该用户数据目录。

## Consequences

- 用户数据与程序二进制生命周期解耦；
- 覆盖升级可以保留记录；
- 备份/恢复可以围绕单一数据根目录设计；
- 未来破坏性 schema 变更必须提供显式迁移，而不能依赖“重新初始化数据库”。

## Invariants

- UI 不直接读写 H2 文件；
- 安装器不得把业务数据库当成安装资产；
- 自动测试不得使用真实用户数据目录；
- 任何删除数据的功能必须是显式用户行为，并具有清晰后果说明。
