# 使用与数据库配置 · 2.0.2

安装 Release 中的 Setup EXE。没有默认手机号和密码，数据库就绪后首次打开创建管理员。

不开数据库也能直接打开软件：显示连接状态页、后台重连，并可正常退出。连接成功后自动进入登录或初始化；这不代表离线仍能操作业务数据。

数据库管理员先准备 PostgreSQL，创建专用数据库与账号。首次启动及升级需执行 DDL 的权限；跨机器连接按实际服务启用 TLS。桌面读取 `SUINING_DATABASE_URL`，连接串只放在部署环境，不写进 README、仓库、截图或日志。例如：

```powershell
$env:SUINING_DATABASE_URL='postgres://用户:密码@数据库主机:5432/库名?sslmode=require'
& '软件安装目录\suining.exe'
```

根据实际安装文件名启动；设置环境变量后需重新打开软件。连接格式错误、数据库未运行或迁移失败不会关闭界面，但业务功能会保持不可用。具体部署者管理数据库账号、权限、可用性和备份。

本地目录沿用 `%APPDATA%\岁宁`：images 保存图片，server-console.log 保存后端诊断，runtime/server.json 仅用于本机运行发现，不含桌面令牌。

旧 H2 文件不会自动转换成 PostgreSQL。升级前保留旧版本与数据副本，先安排迁移并核对业务记录，不能把新数据库的空库初始化当作旧数据迁移成功。卸载不会替您删除用户资料。
