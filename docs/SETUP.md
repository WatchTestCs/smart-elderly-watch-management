# 安装、首次使用与数据保管

从 v2.0.0-preview.1 Release 下载 Setup EXE 或 Portable ZIP。安装版按提示操作；免安装版完整解压后运行 Suining.exe，不要只复制一个 EXE。软件自带运行环境。

## 账号与使用顺序

当前源码默认最大化占满工作区；按 F11 切换无边框全屏，按 Esc 恢复普通窗口。登录页适配窗口高度，短屏收起辅助文案；登录后的首页和业务列表保留滚动，移动端导航独立占位。此显示改动尚未更新至已发布的 v2.0.0-preview.1 安装包。

首次启动创建自己的管理员账号，没有默认手机号或密码。密码 12–20 位，包含英文字母与数字。之后使用自行设置的手机号登录。预览版没有通用密码找回后门，请妥善保管凭据。

先登记监护人、监测阈值档案与老人，再登记并绑定设备。家属通过管理员生成的邀请码注册；健康记录和位置归属由后端校验。空数据库不附带人员或设备样例。

## 离线与备份

查看已有记录、维护档案与公告可离线使用。数据位于 `%APPDATA%\岁宁`：database 保存 H2 文件、images 保存上传图片、logs/server.log 保存轮转服务日志；server-console.log 和 startup-error.log 保存有容量限制的诊断信息。关闭软件后复制整个目录备份；恢复也在程序完全退出后进行。

升级安装、卸载会保留该目录。数据库没有做磁盘加密，Windows 用户账户应妥善保管。旧 MySQL 数据需另做映射与核验，不自动导入原始 SQL。

## 网络接入

默认只监听本机并自动选择空闲端口。部署人员可设置 SUINING_BIND_ADDRESS=0.0.0.0 和固定 SUINING_PORT 供局域网设备访问。程序不主动开放防火墙，互联网接入需加密网关，不直接公开 HTTP 端口。

设备需要有效设备号、随机密钥与对应协议。本轮用真实接口模拟上报，未连接真实手表。短信可选，配置 TENCENT_SMS_APP_ID 与 TENCENT_SMS_APP_KEY 后尝试发送；缺少凭据不影响离线功能。

位置地图无需申请密钥。离线可看坐标与标记，点击“加载在线地图”才连接 OpenStreetMap，底图需要网络；服务失败时继续保留坐标。模拟器可发现正在运行的本机岁宁端口，跨电脑仍通过 --server 指定地址。

当前采用手动升级：关闭软件并备份整个用户目录，核对官方组织 Release 中的版本、哈希和签名，再运行对应安装包。当前源码新增数据库升级前备份和拒绝降级打开保护；不要用旧版本覆盖已升级数据库。没有自动下载并执行更新包的功能。

## 签名与排查

本版本为本机自签，Windows 可能提示发布者不受信任，不自动安装根证书。先核对 Release 提供的 SHA256SUMS.txt。若启动失败，退出后重新打开；仍失败时保存用户目录中的日志排查，分享日志前先去除个人信息。
