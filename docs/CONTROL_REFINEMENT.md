# 控件边界与工具栏验收记录

日期：2026-10-16。本轮在本地 `preview` 工作区完成，承接既有死代码清理，不推送或更新安装包。

## 计划与设计复核

参考用户指定的 [Claude frontend-design 插件](https://claude.com/marketplace/plugins/frontend-design?hl=en-US)及其 [官方 skill 源文件](https://github.com/anthropics/skills/blob/main/skills/frontend-design/SKILL.md)，按规划、对照需求复核、实现、截图评审的顺序工作。

沿用当前字体、Logo 与森林绿配色。界面重点是姓名查询、状态阅读与照护操作，采用字段标签在上、工具栏控件底边对齐、状态文字不伪装成按钮的布局。每个输入控件由一个外壳承担边界和状态；焦点沿这一外框增粗，组合框内部不另画焦点矩形。

使用内置 `image_gen` 生成控件布局参考，再以真实网页实现和验收。图像没有作为 UI 截图或页面代码交付，也没有替换选定 Logo。计划、原始生成提示词和参考图保存在项目本机 `outputs/controls-refinement-20261016/DESIGN_PLAN.md`、`imagegen-manifest.json` 和 `controls-design-study.png`。

## 问题来源与修改

原组合框同时使用 Element Plus 输入外壳阴影、附加区域边界和普通按钮描边；旧样式还给原生输入元素增加焦点阴影。工具栏使用旧栅格与垂直居中布局，导致按钮、状态和查询字段底边错位，生活资料页在窄屏中还会将查询框压得过窄。

- 统一输入、下拉、日期、数量和多行文本的边界所有者。组合搜索框仅在最外层保留一圈描边，内部原生输入、外壳、附加区域与按钮不再另画边框、阴影或圆角框。
- 修复悬停、聚焦、错误和禁用状态；焦点与现有外框合为一条清晰边界，保留可见的键盘提示。
- 十类查询页面统一为原生搜索表单；Enter 与鼠标查询均只提交一次，沿用既有业务方法和接口。
- 姓名字段使用统一宽度与自然换行；操作按底边对齐，睡眠异常改为清晰的状态文字与数字。
- 弹窗字段采用标签在上、控件在下的结构，底部操作统一间距并靠右排列。
- 移除生活资料工具栏和长者表单中的多余栅格，以及不再使用的 ElRow／ElCol 全局注册；删除登录、注册页面中失效的内层边框声明。
