岁宁 2.0.0
岁月有伴，日常安宁。

安装与打开
运行“岁宁-Setup-2.0.0.exe”，按提示安装。也可完整解压免安装包，双击 Suining.exe。
请保留程序文件夹的全部内容，不要只复制其中的 EXE。
适用于 Windows 10 / 11 的 64 位电脑。已内置浏览器引擎、Java 运行环境和文件数据库，无需安装 Node.js、Java、MySQL 或浏览器插件。

窗口与显示
软件默认最大化，占满当前屏幕工作区。按 F11 切换无边框全屏，按 Esc 退出全屏。
登录页按窗口高度安排内容，短屏会收起辅助文案；登录后的首页和业务列表可以滚动。

首次使用
第一次打开创建管理员账号；没有默认账号和通用密码。
密码为 12–20 位，包含字母和数字。请自行保管。
先登记监护人、监测阈值档案和老人档案，再在设备管理中登记、绑定手表。
可生成家属邀请码，让家属创建关联账号。
软件只展示真实录入和设备上报的记录，空白不代表健康状态正常。

数据与备份
默认数据目录：%APPDATA%\岁宁
database 保存内置 H2 数据库，images 保存上传图片，server.log 保存运行日志。
数据库以本机文件保存，密码使用 BCrypt；数据文件没有宣称或实现磁盘加密，应保管好 Windows 用户账户。
备份前退出软件，复制整个数据目录。恢复前也请退出软件，再恢复该目录。
升级安装和卸载程序均保留用户数据。不要在运行中手动改动数据库文件。
旧 MySQL 的数据不会自动导入。原始 SQL 和发布包保留在原项目中，不会作为样例人员数据装入新软件。

设备联网
默认服务仅供本机使用，离线也可查看已有记录、维护档案和公告。
局域网设备接入需由部署人员配置 SUINING_BIND_ADDRESS=0.0.0.0 和固定 SUINING_PORT，并按实际网络设置访问权限；安装程序不会主动开放防火墙。
互联网设备接入需要经过加密网关部署，不应直接将本机 HTTP 服务开放到公网。
设备接入仍需正确设备号、随机密钥与实际手表协议；本轮未进行真实手表联调。
短信通知为可选项，仅配置 TENCENT_SMS_APP_ID 与 TENCENT_SMS_APP_KEY 后尝试发送；离线使用不依赖短信服务。

签名
本次使用本机生成的代码签名证书，应用、安装程序及卸载程序均签名。
这是自签名，能检查文件签名和完整性，并不代表获得公开受信任的 CA 证书或 SmartScreen 信誉。
安装包不会自动把证书加入系统受信任根，也不附带私钥。
公开商业分发如需受信任发布者提示，需要使用真实代码签名证书重新签署。
