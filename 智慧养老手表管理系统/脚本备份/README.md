# 脚本备份（历史文档留档）

这个目录里的文件是**改造过程中留下的历史文档**，不是当前使用说明。
其中的操作步骤描述的是旧版本形态（靠 8 个 `.bat` 脚本启动系统的时期），与现在的用法已经不一致：

| 现在怎么做 | 旧文档里怎么写 |
| --- | --- |
| 双击 `智慧养老管理系统.exe`，按菜单选启动 / 停止 / 初始化数据库 / 启动模拟手表 | 双击 `启动系统.bat`、`启动后端.bat`、`启动模拟手表.bat` 等 |
| 数据库初始化 / 升级由 EXE 的菜单项完成 | 双击 `一键导入数据库.bat`、`升级数据库（…）.bat` |

因此本仓库**没有收录那 8 个 `.bat` 与 `运行说明（起始）.txt`**——它们的功能已被 EXE 完全覆盖。若确需原件，可在本仓库的 `archive-2026-10-13` 标签下取回。

保留在这里的 4 份文档作为开发过程记录：

- `使用说明.txt`（GBK）——第一阶段（邀请码注册）时的使用说明
- `邀请码注册功能说明.md`——邀请码注册的实现说明与接口清单
- `设备侧接口契约.md`——手表端 HTTP 接口约定，写于设备接口开发阶段
- `模拟手表使用说明.md`——模拟手表 `watch-sim` 的参数说明

当前的使用说明请看上一级目录的 [系统使用手册.md](../系统使用手册.md)，接口现状以 `careold/src/main/java/com/example/careold/controller/` 下的源码为准。
